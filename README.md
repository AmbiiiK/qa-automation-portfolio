# QA Automation Portfolio

Automation QA portfolio with Cypress + JavaScript + Cucumber (BDD) and API testing (Postman/Cypress)

### Tech Stack
- Cypress
- Javascript
- Cucumber (BDD)
- POSTMAN
- REST / JSON

## How to run

### Requirements
- Node.js 20+ (use `nvm use` if you have [nvm](https://github.com/nvm-sh/nvm) installed)

### Installation
```bash
nvm use
npm install
```

### Run tests
```bash
# Automation Exercise — BDD login tests
npm run cy:run:ae

# The Internet — BDD login tests
npm run cy:run:practice

# API tests
npm run cy:run:api

# Open Cypress UI
npm run cy:open:ae
npm run cy:open:practice
```

### Run by tag
```bash
# Smoke tests only
npm run cy:run:smoke

# Regression tests
npm run cy:run:regression
```
